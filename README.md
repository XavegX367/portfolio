# Portfolio Project

Dit is mijn portfolio-project gebouwd met [React](https://react.dev/) en [Vite](https://vitejs.dev/).

## 📦 Installatie

1. **Kloon de repository:**
   ```sh
   git clone https://git.fhict.nl/I504610/portfolio-sem3
   cd portfolio-sem3
   ```
2. **Installeer de dependencies:**
   ```sh
   npm install
   ```
3. **Start de ontwikkelserver:**
   ```sh
   npm run dev
   ```
4. Open de lokale server in je browser (standaard `http://localhost:5173`).

## 🚀 Builden voor productie

Om de applicatie te builden voor productie, gebruik:

```sh
npm run build
```

Dit genereert een `dist/` map met geoptimaliseerde bestanden.

## ⚡ Technologieën

- React
- Vite
- JavaScript
- CSS/TailwindCSS
